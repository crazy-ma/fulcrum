# 字体资源与许可证

本目录中的字体由项目本地托管，页面运行时不访问第三方字体服务。

## Albert Sans

- 包：`@fontsource-variable/albert-sans`
- 版本：`5.3.0`
- 来源：Fontsource
- 上游字体：Albert Sans
- 许可证：SIL Open Font License 1.1
- 完整许可：`albert-sans/OFL.txt`

## Noto Sans SC

- 包：`@fontsource-variable/noto-sans-sc`
- 版本：`5.3.0`
- 来源：Fontsource
- 上游字体：Noto Sans Simplified Chinese
- 许可证：SIL Open Font License 1.1
- 完整许可：`noto-sans-sc/OFL.txt`

字体文件保持 Fontsource 提供的可变字体和 Unicode 分片结构，避免合并或修改字形数据。
