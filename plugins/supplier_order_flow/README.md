# 供应商订单收发桥接插件

这个目录只保留 Fulcrum 插件侧的轻量入口，不再承载收发单业务系统。

## 当前边界

- Fulcrum 负责企微消息接入、文件接入、出站任务、Open API 和 Open Webhook。
- `supplier-order-admin` 负责供应商、批次、发单、回传解析、导入和业务后台。
- 本插件只做收发单相关消息识别和帮助提示，不解析 Excel、不写业务表、不调用业务系统。

## 单群关闭

优先使用 Fulcrum 群详情页里的插件作用域开关：把“供应商订单收发”设为“群内强制停用”。

如果群还没进入群管理表，也可以在 bot 插件绑定配置里增加：

```json
{
  "disabled_conversation_external_ids": ["R:需要关闭的企微群ID"]
}
```

被停用的群不会进入本插件的匹配和处理逻辑；入站事件是否继续推给独立收发单系统，仍由 Open API 应用的 Webhook 授权渠道决定。
