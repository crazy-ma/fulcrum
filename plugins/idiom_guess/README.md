# 看图猜成语 · Fulcrum 独立插件

版本：1.0.2(排行榜显示群昵称而不是 wxid;定时开局改为清单声明,无需宿主补丁)。由 Hao 的旧后台插件移植，内含原有 456 道题和 456 张 PNG；不需要旧后台、Flask、外部题库 API 或新 Python 依赖。

支持微桥 WeBridge、微信 iPad、Windows 微信和企业微信的受管群；当前版本不声明 Telegram 或私聊支持。

## 安装与使用

1. 平台管理员进入 `/platform/plugins`，上传 `idiom_guess-1.0.0.zip`。
2. 新插件默认仅平台可见。把可见范围开放给自己的企业或指定套餐。
3. 企业后台把插件绑定到机器人，在目标群启用插件。群的运行模式需要是“正常运行”。
4. 群成员发送 `猜成语` 或 `看图猜成语` 开局，然后直接发送答案。答错保持安静，答对公布发音、解释、出处、造句，并发送本群排行榜。

进行中再次发送开局词不会跳题。默认一局 30 分钟，过期后可以重新开局；不主动公布超时答案。有效分钟数设为 0 表示不过期。答案沿用原插件的空白、常用标点、`答案：` 前缀归一化，不接受近义词或别名。

题目按插件绑定顺序循环；不同企业和机器人拥有独立进度，群游戏和答对题数分别隔离。排行榜统计答对题数，不读写平台通用积分。默认答对后 1 秒将排行榜交给统一发送队列，实际送达时间取决于渠道和手机状态。

回复样式遵循 Fulcrum 的统一渠道设置；旧后台的 `reply_mode` 配置不再单独维护。历史分数不会自动导入，新安装从 0 开始。

## 每日自动开局

核心游戏只需要 ZIP。完整的“打开开关后每天自动运行”还需要随交付提供的 `fulcrum-idiom-scheduler.patch`，在 Fulcrum 代码目录执行 `git apply <补丁路径>`，然后重启服务。补丁基于上游 `1fa31ae`，只给现有扫描器增加本插件的计划，不修改数据库。

安装调度补丁后，在机器人插件配置中开启“每天定时开局”，设置北京时间（默认 20:00）。开关默认关闭。到点后向已启用本插件、正常运行的受管群发送同一道新题；不需要群成员先发消息。已退出的群、停用渠道、关闭的群作用域和平台停用插件均跳过。

每天同一绑定最多开局一次；错过时间会补当天的一题，不补历史日期。定时开局替换旧的进行中题目。群可以关闭本插件，或覆盖 `scheduled_enabled=false` 排除定时开局；每天的时间由机器人插件配置统一决定。当天计划执行结束后才新启用的群，从次日开始参加。

微桥发图复用框架文件缓存和协议适配器；服务器 `PUBLIC_BASE_URL` 必须是手机能访问的地址。电脑浏览器能打开后台不等于手机能下载题图。

## 升级和维护

后续上传相同编码的新 ZIP 即可升级。运行状态和分数存放在 Fulcrum 现有插件状态表中，按企业和绑定隔离，不写入插件安装目录；替换 ZIP 不会清掉这些状态。插件回滚只回滚代码，不回滚分数。

如果运行仓库的固定插件目录检查，把 `idiom_guess` 加入 `FULCRUM_PRIVATE_PLUGINS`（已有多个值时用逗号追加）。这是私有目录校验设置，不影响插件加载。

源码、素材和题目来自用户服务器 `/opt/wechat_bot_iphonehook/share/idiom_guess_plugin`。本包用于用户自己的部署；原分享包未标明题库的再分发许可，公开分发素材前应另行核对来源。
